# BlockRadia desktop release

Search public blockchain addresses, inspect balances and transaction history, and explore counterparties in the wallet graph. An internet connection is required for live data. The interface defaults to English and can be changed in Settings. No wallet connection or private key is required.

- **Windows x64:** verify the publisher signature and open the portable EXE.
- **macOS:** choose arm64 for Apple Silicon or x64 for Intel. Open the signed, notarized DMG and drag BlockRadia into Applications, or extract the ZIP.
- **Linux x64:** verify the signed checksum manifest, then make the AppImage executable and run it. If FUSE is unavailable, extract the tar.gz archive and run the executable inside.

Sign in to GitHub with repository access to download. Verify `SHA256SUMS.txt.sig` using the public key you obtained from the maintainer before checking the package hash. See [release verification instructions](https://github.com/gumonoid/blockradia/blob/main/docs/RELEASE_SIGNING.md).
