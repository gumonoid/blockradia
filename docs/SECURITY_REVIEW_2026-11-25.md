# BlockRadia security assessment, 25 November 2026

Reviewed revision `102cca4` on `fix/private-investigations-and-bot-isolation`. This assessment covers the working branch, the Electron request boundary, the API gateway and the Telegram bot. Priorities below describe release impact. The production revision, installed release binaries, live Telegram user data and hosting configuration were outside the verification scope. The bot deployment template selects a different branch in `render.bot.yaml`.

| Priority | Finding and evidence | Corrective action and acceptance criterion |
| --- | --- | --- |
| High, service availability | At startup and hourly, the API downloads up to 60 MB of OFAC XML. It simultaneously retains bytes, a decoded string and a complete parsed tree. This can exhaust a small hosting instance during a routine refresh. Code inspection, `server/research.mjs:9–24` and `server/start.mjs:28`. | Integrate the existing bounded parser from `2f9b4fe`, absent on this branch. Run the full-feed refresh under the deployment memory limit and check that requests continue to succeed. |
| High, AML decision integrity | The shared review validates individual rows but accepts one to three providers without checking the complete expected set. Duplicate or omitted providers can still satisfy the calculation for green when all other checks pass. This requires an incomplete or erroneous upstream response. Code inspection, `lib/aml-review.ts:7–12` and `:33`. | Validate unique required provider IDs, expected per-provider checks and source domains for each network. Preserve available evidence while marking incomplete coverage yellow. |
| High, desktop feature availability | The new desktop AML panel uses plain fetch. Electron requires an application header. A normal panel-shaped request received 403 from the real desktop handler before it called the API. Under identical conditions the existing application client reached the handler's test provider. `components/explorer/AMLPanel.tsx:21`, `desktop/security.cjs:16`, `lib/explorer-client.ts:3`. The UI smoke test intercepts this request before the Electron handler. | Use the existing application client. Verify the scanner cards in packaged Electron through the real protocol handler with only upstream I/O mocked. Keep the header requirement. |
| Medium, user privacy | The watch monitor retains a copy of the watch list across an awaited notification and then writes back the entire copy. A concurrent unwatch or account deletion can be overwritten. Code inspection, `bot/handler.mjs:459–462`. | Re-read the watch after asynchronous work and condition the update on the original subscription identity. | Medium, service and desktop availability | The portfolio, general upstream RPC and desktop shared API client decode entire JSON responses before processing. Large provider results can consume memory before limits on displayed rows take effect. ## Checks and results

- [Nmap 7.993](https://nmap.org/dist/) confirmed that the test gateway's TCP port 51183 on 127.0.0.1 was open while the process was serving and closed after shutdown. The scan covered that specific test port. The Windows binary was extracted locally after checking its SHA-256 against the publisher's digest.

- npm audit queried the public npm registry for both lockfiles, including development dependencies. Both returned zero known advisories.
- Gitleaks 8.30.1 scanned Git history across local refs and reported 153 scanned commits. Both generic-key matches were verified as test fixtures in `tests/security.test.mjs` and `tests/archive-history.test.mjs`. An additional Git pattern search for project-specific key formats found no matches. These checks cover local Git history. The previously pasted Blockscout credential should be rotated separately.
- All 47 selected security, gateway, AML scanner and Telegram regression tests passed. Provider calls and Telegram messages in these tests use fixtures.
- Windows netstat identified a single listening socket owned by the isolated gateway process on loopback. curl confirmed HTTP 200 for health, 404 for the root, 405 for POST, 400 for an invalid network and 403 for a cross-origin request. Each response contained no-store and nosniff headers. This exercised the real HTTP gateway on a local-only binding. Production uses a different listener and reverse proxy.
- A TypeScript syntax-tree review inspected 50 application and desktop source files for selected injection and external-launch sinks. Electron has renderer sandboxing, context isolation and main-frame checks. The checked release workflow pins action revisions and restricts write permissions to the publishing job. Both Dockerfiles select a non-root runtime user. The local Docker engine was unavailable, so container images and OS libraries were not scanned.

The memory and concurrent deletion findings are based on control flow. No load test was performed against public servers and no live user records were accessed. Passing dependency checks and the existing test suite do not establish that the application is free of vulnerabilities.

## Remediation on the working branch

The findings above describe the original revision. The branch now includes the bounded OFAC parser and its constrained-heap regression. New provider-response limits count bytes from the decoded stream before JSON parsing. Portfolio processing samples at most 100 token records per address and marks truncated results as partial.

Both AML consumers now require coverage from each expected provider, its matching origin, and the expected check count before producing green. The Windows package was built and exercised through its Electron protocol handler using a separate profile and fixture provider responses. Its wallet panel displayed the scanner card.

The Telegram monitor verifies subscription identity after asynchronous operations. A regression deletes the user's data while an AML notification is awaiting delivery and verifies that the database remains empty. Group history uses UTC and personal timezone settings require a private chat. Ordinary AML refresh commands honor the process-wide cache and a failure retry cooldown. The private admin panel retains its explicit refresh override.

Verification included the full 265-test suite, TypeScript, the desktop build and Windows package smoke test. The additional deletion regression passed in a subsequent run of all 21 Telegram tests. Deployment and release promotion were outside this remediation.
